# AI Better

二哥（沉默王二）的 AI 原创内容仓库。目前收录「王二讲Agent」系列：AI Agent 面试题的逐题解答，以及每道题配套的口播视频工程。

在线阅读：[javabetter.cn/ai/video/](https://javabetter.cn/ai/video/)

## 目录

- `video/`：AI Agent 面试题逐题解答，一道题一篇，题目总览见 [readme.md](video/readme.md)
- `script/`：每道题对应的 Remotion 视频工程，`shared/` 是共用的组件、工具和素材，`*/output/*.mp4` 是最终成片
- `sucai.md`：选题素材
