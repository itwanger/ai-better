# 阿基米德原理

按制作或接手工具分组，再按版本存放。各版本的 `output/` 是成片位置；`preview/` 保留预览与原版快照。协作项目按可核实的来源/接手工具归类，不表示该工具独立完成所有工作。

- [namiwork/codex-revised](namiwork/codex-revised/)：纳米 Work 原交付，Codex 接手优化第 1 章；原交付快照保留在 preview。
- [namiwork/kimi-original-export](namiwork/kimi-original-export/)：沿用旧目录所标识的 Kimi 原版导出工程；其中来源记录继承自返修版，不据此认定独立作者。
- [namiwork/memphis](namiwork/memphis/)：纳米 Work + Kimi 实测案例的孟菲斯版；以项目最新进度核对交付状态。

共享动画库、字体及基础色板在 `../shared/`；配音与时间轴属于具体版本，不混用。
