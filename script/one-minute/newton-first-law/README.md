# 牛顿第一定律

按制作或接手工具分组，再按版本存放。各版本的 `output/` 是成片位置；`preview/` 保留预览与原版快照。协作项目按可核实的来源/接手工具归类，不表示该工具独立完成所有工作。

- [codex/three-preview](codex/three-preview/)：Codex 接手的 Three.js 预览；历史稿件含 Qoder 修改，不能视作单工具独立创作。
- [deepseek-harness/3d-book](deepseek-harness/3d-book/)：保留早期 3D 书籍工程及 DeepSeek Harness V3，未拆分已有 Composition。
- [unattributed/memphis](unattributed/memphis/)：孟菲斯版；项目进度未明确标注制作工具，暂存 unattributed，避免凭画风推断。

共享动画库、字体及基础色板在 `../shared/`；配音与时间轴属于具体版本，不混用。
