# 欧姆定律

按制作或接手工具分组，再按版本存放。各版本的 `output/` 是成片位置；`preview/` 保留预览与原版快照。协作项目按可核实的来源/接手工具归类，不表示该工具独立完成所有工作。

- [workbuddy/codex-reviewed](workbuddy/codex-reviewed/)：WorkBuddy 制作、Codex 返修、DeepSeek Harness 导出；保留一份接力工程，原版快照在 preview。

- [codex/super-mario-v1](codex/super-mario-v1/)：超级玛丽风格第一章约27秒有声预览；复用接力版原配音，新画面由Codex制作，待用户审片。

共享动画库、字体及基础色板在 `../shared/`；配音与时间轴属于具体版本，不混用。
