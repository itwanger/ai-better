# 一分钟系列共享组件

- `huashu/<上游提交>-<适配代码哈希>/runtime/`：10 个工程共用的形变、描画、公式与相机运行库，连同 MIT 许可及来源记录一起保存。项目的 `remotion/src/huashu` 是相对软链接。
- 同版本 `fonts/`：共用的中文与数学字体，保留 OFL 及字体许可；项目 `remotion/public/huashu-fonts` 是相对软链接。
- `styles/memphis-v1.ts`：四个孟菲斯工程共用的基础色板；项目保留薄的导出入口，以及各自的参数、对象颜色与覆盖值。
- `../../shared/remotion/components/`、`../../shared/tools/`、`../../shared/config/`：原有全系列通用组件、配音/字幕/导出工具和默认配置，继续共用，无需在本目录复制一份。

通过一分钟 Skill 的 `install_huashu.py --project <项目绝对路径>` 安装动画库和字体时，会自动复用本目录；升级会产生新版本目录，不覆盖旧项目引用的固定版本。已被项目修改过的副本会拒绝替换，须先核对差异。外部独立项目仍可以使用本地副本。

主题专属场景、稿件、音频、字幕时间轴、锁文件和审片进度不放入全局共享目录。共用的代码保持版本固定；修改某期效果应先在该版本内覆盖，不直接改动所有旧片。
