# 视频画面规范

Claude Code（`ergo-remotion-video` Skill）和 Codex 制作二哥视频，画面都按这里执行。目录和命令见 [WORKFLOW.md](WORKFLOW.md)，版式细节见 [用户偏好](https://github.com/itwanger/toBeBetterJavaer/blob/master/.claude/skills/ergo-remotion-video/references/USER_PREFERENCES.md)。

## 一、当前风格

- 冷白背景，顶部完整章节导航（当前章黑底白字），底部单行字幕和按章节分段的进度条。
- 全片一套色调，颜色只从共享色板 `C` 取。蓝色主色，铁锈橙强调，绿色只表示正确，深色写正文，灰色写次要信息。
- 必须有容器时用共享卡片 `card`，直角、蓝色细边、无模糊的灰色偏移阴影。不做卡片套卡片，也不做虚线大框里放几张卡片的结构。
- 原稿配图完整展示，套卡片外框，取景框和原图同宽高比。信息量大的配图用 `FigureFocus` 做镜头聚焦。

## 二、画面靠动画，不靠文字

字幕已经承载完整的语言，画面只负责动画和视觉效果。每做一个画面，先问一句，这个意思能不能用界面操作、物体运动或图形变化表达？能，就不写字。

- 画面上只留短标签，术语名、产品名、模型型号、数值、坐标轴名。整句、问句、结论和台词都不上画面。
- 情绪不写骂人的字。“蠢”“Agent 不好用”这类台词改成漫画符号，比如锯齿气泡加 `#@!` 乱码、青筋符号。
- 概念用语义图形代替词语。示例画成文档，格式画成花括号，约束画成盾牌，格式错位画成裂开的花括号，逻辑断裂画成断开的节点链。
- 说明卡、说明列只写短标题加一个关键词或数值，不写成句子。

## 三、一章是一个连续画面

- 不再一段配一个场景、到点硬切。一章先定两到三个贯穿全章的主角，比如 Claude Code 窗口、质量曲线、模型标签。段落之间让主角移动、缩放、变色，承担新的含义。
- 前面提出的问题，在后面同一个对象上解决。比如第 3 段画出忽高忽低的质量折线，第 5 段在同一张图上让旧折线变灰，绿色上升线覆盖上来。
- 暂时用不上的主角退到背景（透明度 0.1 到 0.15）或淡出，主体区域不能只剩标题。
- 主次靠大小、明暗、背景点阵和跟随主角移动的焦点柔光（`Spotlight`）区分。
- 原稿配图作为一段讲解的落点，至少停留 3 秒左右。关卡台阶这类每章重复的环节，和原稿配图抢时间时可以省掉。

## 四、动效

- 位置、缩放、透明度都按关键帧插值，缓入缓出。元素在术语起音前 4 到 6 帧开始入场，弹出时带一点回弹。
- 折线和数据点同步出现，按点逐段画线，不按路径总长度画，否则线头和点会对不上。
- 元素稳定后不循环脉动。表示“正在工作”的思考标记可以持续旋转。

## 五、共享组件

|组件|文件|用途|
|---|---|---|
|`track`、`life`|`Stage.tsx`|按关键帧插值；按入场和淡出帧算透明度|
|`Actor`|`Stage.tsx`|以中心点定位主角，位置、缩放、透明度由调用方按帧计算|
|`Spotlight`|`Stage.tsx`|背景点阵加跟随焦点的柔光|
|`ClaudeCodeWindow`、`CodexWindow`|`ProductWindows.tsx`|产品界面示意，打字、思考标记、回复逐行出现、`/model` 菜单|

新章节从 [examples/Stage.example.tsx](remotion/examples/Stage.example.tsx) 复制起步，其余组件见 WORKFLOW 的共享场景组件表。
