title: 真狠啊，DeepSeek 开放全家桶 API。
---

11 月 13 日，DeepSeek 发了一条公告，官方 App 和网页端背后的整套能力，全部通过 API 开放给开发者。

为了演示这套接口怎么用，官方还在 GitHub 上开源了一个 `chat-demo`。填上 API Key，就能复刻一个 DeepSeek 出来。

恭喜看到这里的你，已经成功击败 30% 的学习者。

**那聪明的你一定会问，实际用起来效果怎么样？**

先看最常用的联网搜索、深度思考搜索和读链接。以前想让模型上网查资料，得自己对接第三方搜索引擎，先让模型判断要不要搜，再写代码抓网页，最后把正文放回提示词。现在用 `deepseek-flash`，只要在请求里打开 `deepseek_web_search`，搜索、抓取和整理网页的步骤都由 DeepSeek 服务端完成。

在非思考模式下，模型会根据问题自动搜索网页或图片，并在回答里标注引用来源。切到深度思考模式后，模型会在推理过程中边想边查，自己完成搜索、打开网页、在网页里查找关键词这些操作。

![](https://cdn.paicoding.com/stutymore/deepseek-app-api-02-chat-demo-search-20261115190430-d0483cf5.gif)

如果打开 `deepseek_read_url`，模型会自动抓取链接里的正文再回答。翻看 `chat-demo` 的源码，还能看到这样一个细节，服务端抓完网页后，返回结果里的正文字段是空的，网页内容被服务端加密后存进了签名字段 `signature`。下一轮追问时，前端会删掉上一轮的思考过程和搜索结果，减少上下文占用的 Token；读链接的记录则连同签名原样传回，由服务端解密后把网页正文拼回上下文。这样前端既拿不到网页明文，也不用自己保存和管理长文本。

恭喜看到这里的你，已经成功击败 50% 的学习者了。

**那聪明的你肯定会继续问，上传一份带图表的 PDF 或者扫描件，怎么办？**

这就需要文件输入和 OCR 接口了。文件上传时有三种解析方式，代码、Excel 和电子书这类文件走基础模式，转换成 Markdown；只需要文字的可以走纯文字识别，文档里的图片会被丢掉；带架构图、折线图的 PDF 或者 PPT，走图文混排解析。

不仅会提取文字，还会识别出页面里的图表并裁剪成图片，按原来的排版位置和文字放在一起交给模型。

![](https://cdn.paicoding.com/stutymore/deepseek-app-api-03-files-vs-ocr-20261115190430-57f20340.gif)

如果你想做拍照搜题、发票识别或者合同审查这类应用，需要把识别出的文字存进自己的数据库，就可以单独调用 OCR 接口。它除了输出 Markdown 文本，还会给每段文字标上坐标，记录这段文字在页面上的位置。

恭喜看到这里的你，成功击败 70% 的学习者了。

**聪明的你可能会继续问，语音识别和语音合成效果如何？**

语音识别支持普通话、粤语、英语等 `21` 种语言。在 `chat-demo` 里点麦克风开始说话，输入框会实时显示音频频谱，说完后语音就会转成文字发出去。语音合成内置了一男一女两种音色，会自动过滤掉 Markdown 符号，而且是流式返回的，服务端生成一段音频就先发一段，浏览器收到就能播放。

翻看 `chat-demo` 的源码还能看到两个细节。一是语音识别只接收 WAV 或 Opus 格式，前端绕开了浏览器默认输出 WebM 的录音组件，改用 Web Audio 采集音频并在内存里拼上 WAV 文件头；二是流式合成返回的是 `16` 位音频流，每个采样点占 `2` 个字节，前端会把网络分片末尾多出来的 `1` 个奇数字节暂存起来。

![](https://cdn.paicoding.com/stutymore/deepseek-app-api-04-voice-and-pricing-20261115191242-2cf5590e.gif)

恭喜看到这里的你，成功击败 90% 的学习者了。

**最后聪明的你还会问，我们能用这些 API 做什么？**

DeepSeek 负责人崔添翼是这样讲的：“下一个超级 App 不必是面向所有人的一个超级 App。现在，每个人都有能力创造一个超级 App，它也可以是只属于你一个人的超级 App。”同一天，DeepSeek Harness 还上线了实验性的「DeepSeek 会话导入」插件，可以把你在官方 App 里的历史会话导入桌面端。

过去想做一个能联网搜索、能识别文档、还能听会说的应用，得去四五家平台注册账号，分别对接各家的 SDK。现在一个 DeepSeek API Key 就够了。

比如开会时录一段音，用语音识别转成文字，再让模型整理出待办事项；拍一张发票，用 OCR 识别出文字，把金额提取出来填进表格；或者用搜索和抓取接口收集你关注的行业动态，整理成文稿，再用语音合成，后面我就打算把视频的声音用 DeepSeek 的 ASR 试一下。

恭喜你升到王者段位了，成功击败 99% 的学习者。

最后简单总结一下，DeepSeek 这次开放的全家桶 API，在对话接口里加入了联网搜索、深度思考搜索、读链接、文件输入和内容安全审核，同时把搜索、抓取、OCR、语音识别和语音合成做成了五个独立接口，还开源了能复刻官方 App 体验的 `chat-demo`。
