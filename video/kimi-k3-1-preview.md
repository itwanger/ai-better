24 秒，一台复古电脑，屏幕里是 Kimi Code 的终端，模型一栏写着 Kimi K3.1，正在用 Three.js 写一个 3D 场景。

到当天下午 4 点半，这条推文的曝光量已经超过 94 万，点赞 1.2 万。

更有意思的是，10 月 22 日，大模型竞技场 Arena 上冒出一个匿名模型，叫 Kibitz。你问它是谁，它说自己是 Kimi。

一个没发布的模型，凭什么被网友提前认出来？厂商又为什么要先把它放到 Arena 上让大家盲测？

我翻了 Kimi 官方的预告推文、K3 的官方技术博客和 GitHub 模型卡、Arena 官方的排行榜政策和 FAQ，还有 AiBattle、ChrisGPT 这几位爆料者的原帖，帮你把这件事讲清楚。

哈喽大家好，我是二哥呀。今天用 3 分钟，给你讲清楚 Kimi K3.1 到底透露了什么。

**先说第一件事，这条预告透露了什么。**

先说清楚，截至 10 月 23 日下午，官方没有公布 K3.1 的参数、价格和跑分，只给了一个名字和一段演示。

名字里是 3.1，不是 4。这说明它大概率是 K3 的迭代版本，而不是换了一代架构。

那 K3 是什么水平？按 Kimi 官方技术博客，K3 在 7 月 16 日发布，总参数 2.8T，是官方口中全球第一个开源的 3T 级模型，支持 100 万 Token 上下文和原生视觉。GitHub 模型卡写明，它是 MoE（混合专家）架构，每个 Token 只激活 896 个专家里的 16 个，激活参数 104B，完整权重在 7 月 27 日开放。官方博客也坦白说了，整体表现仍然落后最强的闭源模型。

【截图：Kimi K3 官方参数卡；风格：data-board；截图目标：展示 2.8T 总参数、104B 激活参数、896 选 16 专家、100 万上下文；关键词：MoE、2.8T、1M Context】

预告视频选择在 Kimi Code 里写 3D 场景，不是聊天，不是写诗。官方想让你看的重点，就是编程和前端生成。

一句话概括，K3.1 的预告只给了方向，没给答案。

**那聪明的你肯定想到了：Kibitz 是怎么被认出来的？厂商为什么要先上 Arena？**

先说 Arena 的规则。Arena 官方政策写得很清楚，厂商可以把没发布的模型用匿名代号放上去，用户在对战模式里看不到名字，投完票才揭晓。投票攒到评分稳定，至少 1000 票，结果私下发给厂商，然后模型下架。

所以对厂商来说，Arena 就是一场真实用户的盲测。没有品牌光环，只看谁的回答更好。

再说怎么认出来。第一条线索是自报家门。10 月 22 日，AiBattle 发帖说 Kibitz 自称是 Kimi，而且在 Code Arena 里出现得特别频繁。

但他紧接着补了一句，在 Code Arena 里问身份并不可靠，GLM 等模型有时也会说自己是 Kimi。

不是自报家门就算数。

第二条线索是代号规律。按智东西 7 月的报道，K3 发布前在 Arena 上的匿名代号是 Kivine，再往前 K2.5、K2.6 是 Kiwido 和 Kiwire，全是 Ki 开头。Kibitz 正好对上。

【截图：Kimi 历代 Arena 匿名代号对照；风格：swimlane；截图目标：Kiwido、Kiwire、Kivine 到 Kibitz 的时间线；关键词：Arena、匿名代号、Kimi】

第三条线索是分词器，也就是 Tokenizer。同一段文字，不同厂商的模型切出来的 Token 数不一样，有网友据此推测，同时出现的另一个匿名模型 Kalmia 像是 Qwen。这条目前只是网友传闻，没有官方确认。

再加上爆料者 ChrisGPT 在 10 月 23 日上午引用官方预告，说 K3.1 会在明天或者下周一发布。这同样是爆料，以官方为准。

一句话概括，单条线索都不可靠，几条线索拼在一起，才让大家敢押注。

**那聪明的你肯定又要问了：这对我们意味着什么？**

说实话，现在网上流传的 Kibitz 作品，大多是 3D 城堡、像素宝塔这类单个提示词的演示，而且有网友自己也说，效果波动很大，五十次生成里才挑出一个满意的。

Arena 的匿名模型没有 API，我也没有办法拿它跑真实项目。这些演示能说明它会画，说明不了它能扛住你的工程。

【截图：网友 Arena 实测作品合集；风格：checklist-card；截图目标：真实截图，展示 Kibitz 生成的 3D 场景，并标注“网友演示，非官方”；关键词：Kibitz、Arena、3D 生成】

所以我的态度是观望。等官方把参数、价格和跑分放出来，再决定要不要在 Claude Code、Codex 里把它切换成主力模型。

**最后简单总结下。**

Kibitz 自称 Kimi 是线索，官方模型卡和跑分才是证据。

另外，如果你想第一时间试，可以现在就去 Arena 的对战模式多跑几轮编程题，投完票就能看到对面是不是 Kibitz，比看别人挑过的截图靠谱。
